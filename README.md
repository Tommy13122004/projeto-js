# Diretório de Utilizadores
App simples que lista utilizadores de uma API com pesquisa em tempo real.
## Funcionalidades
- vai buscar utilizadores a uma API
- mostra-os em cartões
- pesquisa por nome em tempo real
## Tecnologias usadas
- HTML
- CSS
- JS
## Fonte dos dados
Os dados dos utilizadores vêm da [JSONPlaceholder](https://jsonplaceholder.typicode.com/), uma API pública gratuita para testes.

## Como correr

1. Clonar o repositório: `git clone https://github.com/Tommy13122004/projeto-js.git`
2. Abrir pasta no VS Code
3. Abrir com o Live Server (extensão no VS Code)
É preciso abrir com um servidor local (ex.: Live Server), porque a app usa fetch.
